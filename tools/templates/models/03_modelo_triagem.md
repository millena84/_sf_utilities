## Classificação provisória

- Natureza: [Dúvida / Solicitação operacional / Suspeita de defeito / Evolução / Indefinida]
- Assunto: [Regra / Acesso / Dados / Integração / Interface / Outro]
- Motivo da classificação: [Fatos que sustentam o encaminhamento]

| Situação encontrada | Encaminhamento sugerido |
|---|---|
| Pedido de informação ou orientação | Responder com referência, confirmar esclarecimento e atualizar conhecimento quando útil |
| Ação padronizada já disponível | Encaminhar para execução operacional e autorizações aplicáveis |
| Suspeita de comportamento incorreto | Validar esperado versus observado e investigar o defeito |
| Serviço interrompido ou degradado | Acionar atendimento de incidente conforme o processo local; investigar causa em paralelo quando necessário |
| Nova capacidade ou mudança desejada | Usar o modelo de avaliação |
| Falha recorrente, sistêmica ou de investigação relevante | Avaliar análise estruturada de causas / MASP e associação dos registros relacionados |
| Informação insuficiente | Solicitar complementação ou realizar descoberta breve; manter classificação provisória |

> “É uma integração” não define a natureza do pedido. “Já funcionou antes” é indício útil, mas não determina sozinho se existe defeito. Uma mesma demanda pode gerar registros relacionados para atendimento, investigação e mudança.
