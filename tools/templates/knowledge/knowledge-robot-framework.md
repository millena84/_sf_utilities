# Robot Framework para validação de utilitários

## Responsabilidade

Use Robot Framework para cenários de aceitação, integração, comportamento, contratos CLI e validação end-to-end.

## Relação com Python

Python implementa parsers, clientes e bibliotecas de keywords. Robot Framework organiza cenários, executa keywords e gera evidências.

## Regras

- testar casos positivos e negativos;
- validar precheck e exit codes;
- testar ausência de secrets;
- usar fixtures e mocks localmente;
- exigir autorização para testes contra org;
- não colocar lógica complexa em `.robot`;
- registrar logs e resultados.
