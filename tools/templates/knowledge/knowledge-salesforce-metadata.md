# Salesforce metadata

## Visão geral

Descreva tipos de metadata, diretórios, padrões de arquivo, identidade, componentes compostos, dependências, campos sensíveis e regras de documentação.

## Contrato por tipo

Para cada tipo, registre:

- API name;
- diretório source;
- padrão de arquivo;
- identidade;
- estrutura XML;
- campos relevantes;
- campos sensíveis;
- dependências;
- retrieve;
- critérios documentais.
