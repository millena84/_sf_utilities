# Salesforce Metadata API

## Visão geral

Oriente retrieve, deploy, manifests, representações XML, source format, metadata format, componentes compostos e versionamento da API.

## Regras

- não tratar Metadata API como API transacional de dados;
- registrar versão de API;
- validar componentes recuperáveis;
- preservar evidência antes de sobrescrever arquivos;
- usar modo somente leitura quando a finalidade for documentação.
