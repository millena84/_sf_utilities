# Templates de SDD e Knowledge

Esta área reúne modelos Markdown para a arquitetura SDD da engenharia de utilitários e agentes Salesforce.

## Estrutura

- `knowledge/`: conhecimentos orientadores por especialidade.
- `specs/`: modelos de especificação e contratos.

## Princípio

O `SKILL.md` define o comportamento da skill. Os arquivos `knowledge-*.md` fornecem conhecimento especializado. As SPECs definem o que deve ser construído e validado.

## Uso

1. Selecione os conhecimentos necessários.
2. Leia as fontes oficiais indicadas.
3. Atualize a SPEC antes da implementação.
4. Execute testes e quality gates.
5. Registre evidências e pendências.
