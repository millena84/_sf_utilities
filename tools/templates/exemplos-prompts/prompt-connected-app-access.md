# Prompt — ConnectedApp e acesso

Use o prompt-base para criar um utilitário de documentação do acesso a `ConnectedApp`.

- Identificar Connected App, perfis, permission sets, escopos e políticas.
- Relacionar OAuth, PermissionSet, Profile, User, NamedCredential e ExternalCredential.
- Documentar existência, configuração e acesso concedido separadamente.
- Nunca expor consumer secret, client secret ou tokens.
- Comparar mudanças de escopo e concessão de acesso.
