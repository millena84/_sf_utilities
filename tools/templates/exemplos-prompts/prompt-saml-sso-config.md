# Prompt — SamlSsoConfig

Use o prompt-base para criar um utilitário de documentação de `SamlSsoConfig`.

## Particularidades

- Identificar provedor, issuer, entity ID, URLs, bindings, certificado e status.
- Relacionar AuthProvider, usuários, perfis, PermissionSet e login flows.
- Nunca expor certificados privados, chaves, segredos ou tokens.
- Avaliar validação de assinatura, mapeamento de identidade e fallback.
- Comparar alterações de endpoint, certificado, mapeamento e ativação.
