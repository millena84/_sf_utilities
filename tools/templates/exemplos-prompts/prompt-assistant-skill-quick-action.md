# Prompt — AssistantSkillQuickAction

Use o prompt-base para criar um utilitário de documentação de `AssistantSkillQuickAction`.

## Particularidades

- Identificar skill, ação, rótulo, objeto, parâmetros e permissões.
- Relacionar AssistantDefinition, AssistantSkill, QuickAction, Flow e Apex.
- Avaliar ações que alteram dados, enviam mensagens ou iniciam processos.
- Diferenciar ação disponível de ação efetivamente executada.
- Comparar alterações de parâmetros, escopo, permissões e comportamento.
