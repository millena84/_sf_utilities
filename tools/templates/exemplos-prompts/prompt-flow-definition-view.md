# Prompt — FlowDefinitionView

Use o prompt-base para criar um utilitário de documentação de `FlowDefinitionView`.

- Identificar Flow, versões, status, versão ativa, versão mais recente e metadata associada.
- Relacionar Flow, FlowDefinition, objetos, automações, subflows e deployments.
- Diferenciar versão ativa de versão mais recente.
- Comparar alterações de status, versão ativa e histórico.
- Não declarar que um Flow está em execução apenas porque existe uma versão ativa.
