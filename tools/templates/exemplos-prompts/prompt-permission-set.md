# Prompt — PermissionSet

Use o prompt-base para criar um utilitário de documentação de `PermissionSet`.

- Diretório: `permissionsets/`; padrão: `*.permissionset-meta.xml`.
- Analisar permissões de objeto, campo, sistema, usuário, Apex, Visualforce, apps, tabs, Connected Apps, Named Credentials, External Credentials e custom permissions.
- Avaliar PermissionSetGroup, muting permissions, Profile, User e integrações.
- Não deduzir usuários atribuídos apenas pelo XML.
- Classificar permissões por impacto e destacar privilégios de alto risco.
- Comparar adições, remoções e mudanças de nível.

Fonte: [PermissionSet Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_permissionset.htm).
