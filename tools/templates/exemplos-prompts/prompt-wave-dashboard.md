# Prompt — WaveDashboard

Use o prompt-base para criar um utilitário de documentação de `WaveDashboard`.

## Particularidades

- Identificar dashboard, workspace, widgets, datasets, filtros e permissões.
- Relacionar WaveDataset, AnalyticsVisualization, WaveLens e WaveApplication.
- Diferenciar dashboard configurado de resultado visualizado por usuários.
- Avaliar exposição de métricas, filtros, compartilhamento e performance.
- Comparar alterações de widgets, datasets, filtros, acesso e layout.
