# Prompt — RecordType

Use o prompt-base para criar um utilitário de documentação de `RecordType`.

- Identificar objeto pai, nome, label, ativo, business process e picklists atribuídos.
- Relacionar PageLayout, Profile, PermissionSet, Flow, ValidationRule e campos.
- Diferenciar disponibilidade do Record Type de atribuição a usuários.
- Comparar mudanças de picklists, layout, status e objeto pai.
