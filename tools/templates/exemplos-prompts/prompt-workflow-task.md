# Prompt — WorkflowTask

Use o prompt-base para criar um utilitário de documentação de `WorkflowTask`.

- Identificar objeto, regra de origem, assunto, descrição, prioridade, status, proprietário e prazo.
- Relacionar WorkflowRule, User, Queue, tarefas e processos de atendimento.
- Diferenciar template de tarefa da execução efetiva.
- Avaliar automações duplicadas e impacto operacional.
- Comparar alterações de proprietário, prazo, prioridade e regra de origem.
