# Prompt — BotBlockVersion

Use o prompt-base para criar um utilitário de documentação de `BotBlockVersion`.

## Particularidades

- Identificar bloco, versão, status, vigência, idioma e dependências.
- Relacionar BotBlock, BotVersion, Flow e implantação do bot.
- Diferenciar versão ativa de versão em rascunho ou arquivada.
- Comparar alterações de diálogo, ações, variáveis e compatibilidade.
- Não afirmar uso em produção sem evidência de publicação ou ativação.
