# Prompt — User e acesso efetivo

Use o prompt-base para criar um utilitário de documentação do acesso de `User`.

- Identificar usuário, Profile, PermissionSets, PermissionSetGroups, Role, licença e status.
- Não expor nome, email ou identificadores pessoais além do necessário.
- Separar permissões concedidas por perfil, permission set, grupo, licença, role e compartilhamento.
- Diferenciar acesso potencial de acesso efetivo a registros.
- Consultar a org somente com autorização e minimização de dados.
