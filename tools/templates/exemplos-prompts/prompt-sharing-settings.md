# Prompt — SharingSettings

Use o prompt-base para criar um utilitário de documentação de `SharingSettings`.

## Particularidades

- Identificar padrões organizacionais, acesso externo, atividade e configurações de compartilhamento.
- Relacionar Organization-Wide Defaults, SharingRule, Role, Group, Profile e PermissionSet.
- Avaliar impacto de exposição, restrição e acesso externo.
- Diferenciar configuração global de regra de compartilhamento específica.
- Não expor detalhes sensíveis de segurança além do necessário.
