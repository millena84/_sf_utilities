# Prompt — ApptAppointmentRelation

Use o prompt-base para criar um utilitário de documentação de `ApptAppointmentRelation`.

## Particularidades

- Identificar relação, agendamentos relacionados, tipo, dependência, ordem e status.
- Relacionar Appointment, ServiceAppointment, WorkOrder, recursos e visitas.
- Não expor dados pessoais ou detalhes operacionais além do necessário.
- Diferenciar vínculo configurado de sequência de appointments efetivamente executada.
- Comparar alterações de dependências, ordem, tipo, duração e status.
