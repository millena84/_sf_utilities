# Prompt — Report

Use o prompt-base para criar um utilitário de documentação de `Report`.

- Identificar pasta, nome, formato, report type, objeto, colunas, filtros, agrupamentos e fórmulas.
- Relacionar CustomObject, CustomField, ReportType, Dashboard, pastas e permissões.
- Diferenciar definição do relatório dos dados retornados em execução.
- Não extrair registros como se fossem metadata.
- Identificar possíveis dados sensíveis nos filtros e campos.
