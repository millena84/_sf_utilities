# Prompt — ApptServiceTerritory

Use o prompt-base para criar um utilitário de documentação de `ApptServiceTerritory`.

## Particularidades

- Identificar território, serviços, recursos, horários, cobertura, regras e status.
- Relacionar ServiceTerritory, Appointment, ServiceResource, WorkType e Field Service.
- Não expor endereços ou geolocalização sensível sem necessidade.
- Diferenciar território configurado de cobertura efetivamente disponível.
- Comparar alterações de cobertura, recursos, horários, regras e status.
