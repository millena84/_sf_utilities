# Prompt — OrderSettings

Use o prompt-base para criar um utilitário de documentação de `OrderSettings`.

## Particularidades

- Identificar habilitação de pedidos, ativação, redução, contratos e comportamento de datas.
- Relacionar Order, Contract, Opportunity, Product2, Pricebook2 e Flow.
- Diferenciar pedido habilitado de pedido efetivamente ativado ou faturado.
- Avaliar impacto comercial, financeiro e operacional.
- Comparar alterações de ativação, datas, contratos e produtos.
