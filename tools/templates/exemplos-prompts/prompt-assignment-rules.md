# Prompt — AssignmentRules

Use o prompt-base para criar um utilitário de documentação de `AssignmentRules`.

- Identificar objeto, regra ativa, entradas e ordem de avaliação.
- Documentar critérios, campos utilizados e ações de atribuição.
- Relacionar queues, users, objetos e automações concorrentes.
- Diferenciar regras de Lead, Case ou outros objetos suportados.
- Não assumir que uma regra está ativa apenas por existir no metadata.
