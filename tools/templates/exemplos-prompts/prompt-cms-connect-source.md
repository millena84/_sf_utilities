# Prompt — CMSConnectSource

Use o prompt-base para criar um utilitário de documentação de `CMSConnectSource`.

## Particularidades

- Identificar fonte, provedor, endpoint, autenticação, conteúdo e status.
- Relacionar CMS, Experience Cloud, ExternalCredential, NamedCredential e componentes.
- Nunca expor tokens, chaves, certificados ou endpoints privados.
- Diferenciar fonte configurada de conteúdo efetivamente sincronizado.
- Avaliar timeout, cache, mapeamento, segurança e tratamento de falhas.
