# Prompt — WorkflowAlert

Use o prompt-base para criar um utilitário de documentação de `WorkflowAlert`.

- Identificar objeto, regra de origem, template de email, destinatários e critérios de disparo.
- Relacionar WorkflowRule, EmailTemplate, User, Queue, Contact, Lead, Case e integrações.
- Não expor endereços ou dados pessoais desnecessários.
- Diferenciar alerta configurado de email efetivamente enviado.
- Comparar mudanças de template, destinatários e regra de origem.
