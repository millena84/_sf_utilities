# Prompt — CustomObjectTranslation

Use o prompt-base para criar um utilitário de documentação de `CustomObjectTranslation`.

- Identificar objeto, idioma, traduções de labels, campos, picklists e record types.
- Relacionar CustomObject, CustomField, RecordType, GlobalValueSet e Translation.
- Diferenciar idioma padrão de tradução configurada.
- Comparar alterações por idioma e elemento traduzido.
- Preservar chaves técnicas.
