# Prompt — LightningMessageChannel

Use o prompt-base para criar um utilitário de documentação de `LightningMessageChannel`.

- Identificar canal, campos, finalidade e exposição.
- Relacionar LWC, Aura, Visualforce e Lightning Message Service.
- Localizar publishers e subscribers quando possível.
- Documentar contrato de mensagem e compatibilidade.
- Alertar mudanças incompatíveis no payload.

Fonte: [LightningMessageChannel Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_lightningmessagechannel.htm)
