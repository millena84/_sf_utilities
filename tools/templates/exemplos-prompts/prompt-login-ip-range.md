# Prompt — LoginIpRange

Use o prompt-base para criar um utilitário de documentação de `LoginIpRange`.

- Identificar origem, perfil associado, faixa IP e limites.
- Tratar endereços e faixas como informação sensível de segurança.
- Relacionar Profile, NetworkAccess, SessionSettings e políticas de login.
- Mascarar valores conforme a política do projeto.
- Comparar adições, remoções e alterações de faixa.
