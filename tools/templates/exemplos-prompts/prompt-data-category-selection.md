# Prompt — DataCategorySelection

Use o prompt-base para criar um utilitário de documentação de `DataCategorySelection`.

## Particularidades

- Identificar objeto, categoria, grupo e associação.
- Relacionar DataCategoryGroup, KnowledgeArticle, usuários e visibilidade.
- Diferenciar seleção aplicada de categoria disponível na taxonomia.
- Avaliar exposição ou restrição de conteúdo.
- Comparar alterações de associação e escopo de visibilidade.
