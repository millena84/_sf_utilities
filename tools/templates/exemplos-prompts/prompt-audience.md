# Prompt — Audience

Use o prompt-base para criar um utilitário de documentação de `Audience`.

## Particularidades

- Identificar audiência, critérios, atributos, status, origem e canais.
- Relacionar Experience Cloud, Digital Experience, usuários, grupos e conteúdo.
- Não expor PII, critérios sensíveis ou segmentos confidenciais.
- Diferenciar audiência configurada de usuários efetivamente elegíveis.
- Comparar alterações de critérios, atributos, status e disponibilidade.
