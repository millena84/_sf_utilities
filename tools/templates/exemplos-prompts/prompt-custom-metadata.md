# Prompt — CustomMetadata

Use o prompt-base para criar um utilitário de documentação de `CustomMetadata`.

- Identificar tipo e registros.
- Separar definição do tipo e registros.
- Extrair campos, valores não sensíveis, relacionamentos e uso no código.
- Relacionar Apex, Flow, PermissionSet e integrações.
- Não confundir Custom Metadata com dados transacionais.
