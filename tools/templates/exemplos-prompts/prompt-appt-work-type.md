# Prompt — ApptWorkType

Use o prompt-base para criar um utilitário de documentação de `ApptWorkType`.

## Particularidades

- Identificar tipo de trabalho, duração, habilidades, território, regras e status.
- Relacionar WorkType, Appointment, ServiceResource, ServiceTerritory e Field Service.
- Diferenciar definição do serviço de appointments efetivamente executados.
- Avaliar duração, elegibilidade, capacidade, habilidades e restrições.
- Comparar alterações de regras, duração, habilidades, territórios e status.
