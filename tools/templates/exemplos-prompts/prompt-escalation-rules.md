# Prompt — EscalationRules

Use o prompt-base para criar um utilitário de documentação de `EscalationRules`.

- Identificar objeto, critérios, tempo de escalonamento e ações.
- Documentar notificações, atribuição, filas, usuários e regras de negócio.
- Relacionar Case, EmailTemplate, Queue, User e configurações de suporte.
- Registrar unidade de tempo e condições de reavaliação.
