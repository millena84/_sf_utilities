# Prompt — WorkflowRule

Use o prompt-base para criar um utilitário de documentação de `WorkflowRule`.

- Identificar objeto, critérios, avaliação e ações.
- Documentar field updates, tasks, email alerts e outbound messages.
- Relacionar campos, templates, usuários, filas, integrações e automações modernas.
- Registrar se a regra é legada e se há Flow equivalente ou concorrente.
