# Prompt — BotSettings

Use o prompt-base para criar um utilitário de documentação de `BotSettings`.

## Particularidades

- Identificar configurações globais de bots, idioma, fallback, privacidade e disponibilidade.
- Relacionar Bot, BotVersion, MessagingSettings, Flow e Omni-Channel.
- Não expor informações de clientes, tokens ou regras internas sensíveis.
- Diferenciar configuração organizacional de comportamento de um bot específico.
- Comparar alterações de fallback, idioma, canais e políticas.
