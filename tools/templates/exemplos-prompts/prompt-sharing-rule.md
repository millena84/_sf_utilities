# Prompt — SharingRule

Use o prompt-base para criar um utilitário de documentação de regras de compartilhamento.

- Identificar objeto, tipo de regra, origem, destino, condição e nível de acesso.
- Relacionar OWD, Role, Group, Queue, Territory, User, SharingSet e ownership.
- Diferenciar concessão de registro de permissão de objeto/campo.
- Avaliar risco de exposição e acesso excessivo.
- Comparar adições, remoções e mudanças de nível.
