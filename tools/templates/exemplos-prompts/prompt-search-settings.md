# Prompt — SearchSettings

Use o prompt-base para criar um utilitário de documentação de `SearchSettings`.

## Particularidades

- Identificar objetos, campos, filtros, relevância, pesquisa global e configurações de busca.
- Relacionar Search, CustomObject, FieldSet, KnowledgeSettings e permissões.
- Diferenciar objeto pesquisável de registro indexado ou encontrado.
- Avaliar exposição de dados em resultados e sugestões.
- Comparar alterações de objetos, campos e relevância.
