# Prompt — SessionSettings

Use o prompt-base para criar um utilitário de documentação de `SessionSettings`.

- Identificar timeout, restrições de sessão, IP, browser, MFA e políticas disponíveis.
- Relacionar SecuritySettings, Profile, LoginFlow e autenticação.
- Diferenciar configuração org-wide de configuração por perfil ou usuário.
- Comparar alterações de timeout e controles de sessão.
