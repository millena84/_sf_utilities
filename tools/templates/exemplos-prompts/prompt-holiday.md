# Prompt — Holiday

Use o prompt-base para criar um utilitário de documentação de `Holiday`.

## Particularidades

- Identificar nome, data, recorrência, duração e calendários associados.
- Relacionar BusinessHours, SLA, Case, escalonamentos e prazos.
- Diferenciar feriado pontual de feriado recorrente.
- Avaliar impacto temporal sobre processos dependentes de horário comercial.
- Comparar alterações de data, duração, recorrência e associação.
