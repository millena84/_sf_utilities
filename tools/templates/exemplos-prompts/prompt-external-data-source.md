# Prompt — ExternalDataSource

Use o prompt-base para criar um utilitário de documentação de `ExternalDataSource`.

- Identificar sistema externo, tipo, protocolo, endpoint, autenticação e configuração.
- Relacionar External Objects, External Services, Named Credentials e AuthProvider.
- Não expor credenciais.
- Diferenciar configuração da fonte externa de objetos externos utilizados.
- Registrar lacunas de contrato e operação.
