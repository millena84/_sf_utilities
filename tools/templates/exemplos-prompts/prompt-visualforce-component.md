# Prompt — ApexComponent / VisualforceComponent

Use o prompt-base para criar um utilitário de documentação de componentes Visualforce.

- Identificar arquivo, atributos, controller, markup, filhos e páginas consumidoras.
- Relacionar ApexClass, ApexPage, objetos, campos e permissões.
- Tratar o componente como unidade reutilizável.
- Comparar mudanças de interface e dependências.
- Não deduzir uso sem evidência.
