# Prompt — Bot

Use o prompt-base para criar um utilitário de documentação de `Bot`.

## Particularidades

- Identificar bot, tipo, canal, status, idioma, versão e contexto de atendimento.
- Relacionar BotVersion, BotTemplate, MessagingChannel, Flow, Apex e Knowledge.
- Diferenciar bot configurado de sessão ou conversa efetivamente iniciada.
- Avaliar escopo de acesso, coleta de dados, fallback e transferência para agente.
- Comparar alterações de status, canais, idioma, versão e dependências.
