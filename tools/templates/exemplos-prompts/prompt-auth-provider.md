# Prompt — AuthProvider

Use o prompt-base para criar um utilitário de documentação de `AuthProvider`.

- Identificar tipo de provedor, fornecedor, parâmetros de autorização, URLs, scopes e configuração.
- Relacionar ConnectedApp, NamedCredential, ExternalCredential, Certificate e PermissionSet.
- Nunca expor client secret, consumer secret, tokens, chaves ou valores confidenciais.
- Diferenciar existência da configuração, tipo de autenticação e uso efetivo.
- Verificar XML, Metadata API, Tooling API e tabela interna.
