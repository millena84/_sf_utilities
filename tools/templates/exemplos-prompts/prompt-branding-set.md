# Prompt — BrandingSet

Use o prompt-base para criar um utilitário de documentação de `BrandingSet`.

## Particularidades

- Identificar conjunto de marca, logos, cores, fontes, imagens e experiências associadas.
- Relacionar Theme, Community, ExperienceBundle, ContentAsset e páginas.
- Não expor assets privados ou links de armazenamento sem necessidade.
- Diferenciar conjunto de marca de aplicação visual efetiva.
- Comparar alterações de logos, cores, fontes, assets e disponibilidade.
