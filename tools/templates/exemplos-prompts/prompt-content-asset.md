# Prompt — ContentAsset

Use o prompt-base para criar um utilitário de documentação de `ContentAsset`.

## Particularidades

- Identificar asset, arquivo, tipo, idioma, versão, pasta, status e canais.
- Relacionar CMS, Experience Cloud, ContentTypeBundle, páginas e componentes.
- Não expor conteúdo confidencial, URLs privadas ou dados pessoais.
- Diferenciar asset armazenado de asset publicado e visualizado.
- Comparar alterações de conteúdo, versão, idioma, status e disponibilidade.
