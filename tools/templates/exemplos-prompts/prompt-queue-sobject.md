# Prompt — QueueSobject

Use o prompt-base para criar um utilitário de documentação de `QueueSobject`.

- Identificar a fila e o tipo de objeto suportado.
- Preservar a relação Queue–SObject.
- Relacionar objetos, regras de compartilhamento, ownership e automações.
- Não documentar QueueSobject como permissão de objeto isolada.
- Comparar inclusão e remoção de objetos suportados.
