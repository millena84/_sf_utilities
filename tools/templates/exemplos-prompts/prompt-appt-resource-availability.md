# Prompt — ApptResourceAvailability

Use o prompt-base para criar um utilitário de documentação de `ApptResourceAvailability`.

## Particularidades

- Identificar recurso, disponibilidade, horários, fuso, território, exceções e status.
- Relacionar ServiceResource, ResourceAbsence, Appointment, WorkType e Field Service.
- Não expor localização individual, agenda pessoal ou informação operacional sensível.
- Diferenciar janela cadastrada de disponibilidade realmente reservável.
- Comparar alterações de horários, exceções, capacidade, território e status.
