# Prompt — VoiceCallChannel

Use o prompt-base para criar um utilitário de documentação de `VoiceCallChannel`.

## Particularidades

- Identificar canal, número mascarado, provedor, região, status, filas e horários.
- Relacionar VoiceCallSettings, ServiceChannel, Queue, BusinessHours e CallCenter.
- Não expor números completos, credenciais ou configurações privadas de telefonia.
- Diferenciar canal configurado de chamada recebida ou realizada.
- Comparar alterações de provedor, região, horários, filas e disponibilidade.
