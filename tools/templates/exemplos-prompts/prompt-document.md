# Prompt — Document

Use o prompt-base para criar um utilitário de documentação de `Document`.

## Particularidades

- Identificar nome, pasta, tipo, extensão, tamanho, proprietário e disponibilidade.
- Relacionar DocumentFolder, conteúdo estático, templates e referências em páginas.
- Não expor conteúdo confidencial nem links de acesso indevido.
- Diferenciar metadata do arquivo e conteúdo binário.
- Comparar alterações de localização, proprietário, disponibilidade e versão.
