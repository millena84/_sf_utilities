# Prompt — CommunityTemplateDefinition

Use o prompt-base para criar um utilitário de documentação de `CommunityTemplateDefinition`.

## Particularidades

- Identificar template, páginas, componentes, navegação, versão e status.
- Relacionar Community, ExperienceBundle, Theme, NavigationMenu e usuários externos.
- Diferenciar template reutilizável de comunidade publicada.
- Avaliar acessibilidade, segurança, conteúdo público e dependências.
- Comparar alterações de páginas, navegação, componentes e versão.
