# Prompt — Network

Use o prompt-base para criar um utilitário de documentação de `Network`.

## Particularidades

- Identificar site, URL, tipo, status, membros, perfis e configurações.
- Relacionar Community, ExperienceBundle, NetworkMember, usuários externos e autenticação.
- Avaliar acesso público, compartilhamento e exposição de dados.
- Diferenciar rede configurada de site publicado e operacional.
- Comparar alterações de URL, status, membros e permissões.
