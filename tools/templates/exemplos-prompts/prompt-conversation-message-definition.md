# Prompt — ConversationMessageDefinition

Use o prompt-base para criar um utilitário de documentação de `ConversationMessageDefinition`.

## Particularidades

- Identificar canal, tipo de mensagem, remetente, destinatário, template e eventos.
- Relacionar MessagingChannel, ConversationVendorInfo, Bot, Flow e EmailTemplate.
- Não expor conteúdo real de conversas, dados pessoais ou credenciais.
- Diferenciar definição de mensagem de mensagem efetivamente enviada ou recebida.
- Comparar alterações de formato, canal, template, eventos e disponibilidade.
