# Prompt — UserManagementSettings

Use o prompt-base para criar um utilitário de documentação de `UserManagementSettings`.

## Particularidades

- Identificar configurações de usuários, delegação, login, criação, permissões e administração.
- Relacionar User, Profile, PermissionSet, Role, LoginFlow e SessionSettings.
- Avaliar risco de privilégio excessivo e administração delegada.
- Não expor credenciais, tokens ou dados pessoais desnecessários.
- Comparar alterações de criação, login, delegação e governança.
