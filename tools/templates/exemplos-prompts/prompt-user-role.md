# Prompt — UserRole e hierarquia de acesso

Use o prompt-base para criar um utilitário de documentação da relação entre usuários e funções.

- Identificar usuário, Role, hierarquia, território, perfil e grupos relacionados.
- Diferenciar função do usuário, perfil, permission sets e acesso a registros.
- Não expor dados pessoais desnecessários.
- Documentar herança potencial de acesso sem afirmar acesso efetivo sem evidência.
- Comparar mudanças de função e impacto na visibilidade.
