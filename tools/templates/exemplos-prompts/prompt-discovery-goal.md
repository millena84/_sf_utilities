# Prompt — DiscoveryGoal

Use o prompt-base para criar um utilitário de documentação de `DiscoveryGoal`.

## Particularidades

- Identificar objetivo, métrica, população, horizonte, modelo e status.
- Relacionar DiscoveryAIModel, datasets, previsões, ações e processos de negócio.
- Diferenciar objetivo configurado de resultado ou recomendação gerada.
- Avaliar cobertura, viés, limiares, explicabilidade e supervisão humana.
- Comparar alterações de métrica, população, horizonte, modelo e status.
