# Prompt — BotBlock

Use o prompt-base para criar um utilitário de documentação de `BotBlock`.

## Particularidades

- Identificar bloco, intenção, variáveis, diálogos, ações, condições e transições.
- Relacionar Bot, BotVersion, Flow, Apex, Omni-Channel e objetos.
- Diferenciar bloco reutilizável de diálogo efetivamente executado.
- Avaliar loops, caminhos sem saída, dados coletados e ações privilegiadas.
- Comparar alterações de lógica, variáveis, condições e transições.
