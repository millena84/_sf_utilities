# Prompt — AssistantContextItem

Use o prompt-base para criar um utilitário de documentação de `AssistantContextItem`.

## Particularidades

- Identificar item de contexto, origem, objeto, campo, filtro e condição.
- Relacionar AssistantDefinition, AssistantSkill, Flow, Apex, User e registros.
- Avaliar minimização de dados, exposição de PII e escopo de consulta.
- Diferenciar contexto configurado de informação efetivamente recuperada.
- Comparar alterações de origem, filtros, campos e permissões.
