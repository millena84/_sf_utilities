# Prompt — WaveDataset

Use o prompt-base para criar um utilitário de documentação de `WaveDataset`.

## Particularidades

- Identificar dataset, origem, campos, dimensões, medidas, atualização e status.
- Relacionar WaveApplication, WaveDashboard, WaveLens, WaveRecipe e fontes de dados.
- Não expor registros, PII, credenciais ou dados comerciais confidenciais.
- Diferenciar dataset definido de dados efetivamente carregados ou atualizados.
- Avaliar qualidade, linhagem, retenção, acesso e atualização.
