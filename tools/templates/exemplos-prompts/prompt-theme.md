# Prompt — Theme

Use o prompt-base para criar um utilitário de documentação de `Theme`.

## Particularidades

- Identificar tema, cores, fontes, tokens, assets, componentes e status.
- Relacionar Community, Experience Cloud, BrandingSet e páginas.
- Diferenciar tema reutilizável de identidade visual aplicada.
- Avaliar acessibilidade, contraste, assets e compatibilidade.
- Comparar alterações de tokens, assets, componentes e versão.
