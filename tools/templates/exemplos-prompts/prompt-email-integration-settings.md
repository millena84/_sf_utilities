# Prompt — EmailIntegrationSettings

Use o prompt-base para criar um utilitário de documentação de `EmailIntegrationSettings`.

## Particularidades

- Identificar integração, sincronização, captura, servidor e opções de segurança.
- Relacionar ActivitiesSettings, EmailServicesFunction, ExternalCredential e usuários.
- Diferenciar configuração de integração de email efetivamente sincronizado.
- Avaliar retenção, privacidade, duplicidade e falhas de sincronização.
- Comparar alterações de servidor, sincronização e políticas.
