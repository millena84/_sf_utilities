# Prompt — AppointmentTopicTimeSlot

Use o prompt-base para criar um utilitário de documentação de `AppointmentTopicTimeSlot`.

## Particularidades

- Identificar tópico, faixa horária, duração, fuso, recurso, território e disponibilidade.
- Relacionar AppointmentTopic, Appointment, ResourceAvailability e ServiceTerritory.
- Não expor agenda individual ou localização operacional sensível.
- Diferenciar faixa configurada de horário realmente disponível para reserva.
- Comparar alterações de horários, duração, fuso, capacidade e status.
