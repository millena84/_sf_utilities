# Prompt — SharingSet e acesso Experience Cloud

Use o prompt-base para criar um utilitário de documentação de `SharingSet` e seus mapeamentos de acesso.

- Identificar perfil, licença, usuário externo, objeto-alvo e campos de mapeamento.
- Relacionar Network, Contact, Account, User, Profile e objetos externos.
- Documentar nível de acesso concedido e condições.
- Diferenciar regra declarada de acesso efetivo.
- Tratar dados de usuários externos como sensíveis.

Fonte: [SharingSet — Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_sharingset.htm)
