# Prompt — DiscoveryAIModel

Use o prompt-base para criar um utilitário de documentação de `DiscoveryAIModel`.

## Particularidades

- Identificar modelo, versão, objetivo, entradas, saída, métricas e status.
- Relacionar DiscoveryGoal, datasets, previsões, avaliações e usuários.
- Diferenciar modelo treinado de previsão efetivamente calculada.
- Avaliar viés, drift, explicabilidade, retenção e impacto decisório.
- Comparar alterações de versão, dados, métricas, objetivo e status.
