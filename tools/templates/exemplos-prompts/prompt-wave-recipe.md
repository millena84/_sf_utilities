# Prompt — WaveRecipe

Use o prompt-base para criar um utilitário de documentação de `WaveRecipe`.

## Particularidades

- Identificar recipe, fontes, transformações, joins, filtros, destino e agendamento.
- Relacionar WaveDataset, WaveApplication, AnalyticsWorkspace e integrações.
- Diferenciar receita definida de execução ou dataset produzido.
- Avaliar linhagem, qualidade, duplicidade, acesso e custo de processamento.
- Comparar alterações de fontes, transformações, filtros, destino e frequência.
