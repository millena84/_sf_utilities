# Prompt — SiteDotCom

Use o prompt-base para criar um utilitário de documentação de `SiteDotCom`.

## Particularidades

- Identificar site, páginas, domínio, componentes, publicação e status.
- Relacionar Community, ExperienceBundle, DigitalExperienceConfig e usuários convidados.
- Não expor domínios privados, dados de usuários ou configurações sensíveis.
- Diferenciar site configurado de site publicado e acessível.
- Comparar alterações de páginas, domínio, componentes e publicação.
