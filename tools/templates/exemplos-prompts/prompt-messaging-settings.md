# Prompt — MessagingSettings

Use o prompt-base para criar um utilitário de documentação de `MessagingSettings`.

## Particularidades

- Identificar configurações globais de mensageria, sessões, consentimento, retenção e disponibilidade.
- Relacionar MessagingChannel, ConversationVendorInfo, EmbeddedServiceConfig e políticas de privacidade.
- Não expor dados de clientes, tokens, endpoints ou credenciais.
- Diferenciar configuração organizacional de conversa efetivamente ocorrida.
- Avaliar impacto em privacidade, jornada de atendimento e conformidade.
