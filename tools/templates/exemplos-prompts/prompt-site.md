# Prompt — Site

Use o prompt-base para criar um utilitário de documentação de `Site`.

## Particularidades

- Identificar nome, domínio, página inicial, classe, status e configuração de acesso.
- Relacionar ApexPage, ApexClass, Community, Network e usuários convidados.
- Avaliar risco de exposição pública e execução sem autenticação.
- Não exibir endpoints ou detalhes que facilitem abuso.
- Comparar alterações de domínio, página, classe e status.
