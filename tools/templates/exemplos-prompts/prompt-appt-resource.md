# Prompt — ApptResource

Use o prompt-base para criar um utilitário de documentação de `ApptResource`.

## Particularidades

- Identificar recurso, tipo, habilidades, território, agenda, capacidade e status.
- Relacionar ServiceResource, Skill, ServiceTerritory, Appointment e WorkType.
- Não expor PII, localização exata ou informações pessoais desnecessárias.
- Diferenciar recurso cadastrado de recurso elegível e disponível para agendamento.
- Comparar alterações de habilidades, território, capacidade, agenda e status.
