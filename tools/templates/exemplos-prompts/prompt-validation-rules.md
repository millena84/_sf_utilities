# Prompt — ValidationRules

Use o prompt-base para criar um utilitário de documentação de `ValidationRules`.

- Identificar objeto pai, nome, fórmula, mensagem de erro, campo de erro e estado ativo.
- Extrair campos referenciados, funções e dependências quando possível.
- Relacionar Flow, Apex, integrações e processos de carga.
- Não interpretar fórmula como regra de negócio completa sem contexto.
