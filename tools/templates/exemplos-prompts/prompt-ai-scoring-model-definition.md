# Prompt — AIScoringModelDefinition

Use o prompt-base para criar um utilitário de documentação de `AIScoringModelDefinition`.

## Particularidades

- Identificar modelo, versão, entradas, saída, métrica, status e finalidade.
- Relacionar AIUsecaseDefinition, avaliação, dados, decisões e permissões.
- Diferenciar modelo de pontuação de score calculado para um registro.
- Avaliar explicabilidade, viés, drift, limites e impacto decisório.
- Comparar alterações de versão, entradas, métrica e limiar.
