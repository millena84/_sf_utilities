# Prompt — ExperienceResource

Use o prompt-base para criar um utilitário de documentação de `ExperienceResource`.

## Particularidades

- Identificar recurso, arquivo, tipo, localização, versão, publicação e status.
- Relacionar ExperienceBundle, DigitalExperienceBundle, Theme e componentes.
- Não expor conteúdo privado, tokens ou URLs internas.
- Diferenciar recurso armazenado de recurso publicado e carregado.
- Comparar alterações de conteúdo, caminho, versão e disponibilidade.
