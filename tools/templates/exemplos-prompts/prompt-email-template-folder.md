# Prompt — EmailTemplateFolder

Use o prompt-base para criar um utilitário de documentação de `EmailTemplateFolder`.

## Particularidades

- Identificar pasta, nome, proprietário e permissões de acesso.
- Relacionar EmailTemplate, usuários, grupos e compartilhamento.
- Diferenciar organização dos templates de autorização para envio.
- Não expor nomes pessoais ou dados de acesso além do necessário.
- Comparar alterações de proprietário, localização e compartilhamento.
