# Prompt — PlatformEvent

Use o prompt-base para criar um utilitário de documentação de `PlatformEvent`.

- Identificar campos, publish behavior, canais e consumidores.
- Relacionar Apex, Flow, Platform Event Channels, Pub/Sub API e middleware.
- Documentar replay, retenção, ordem, duplicidade, volume e falhas.
- Diferenciar Platform Event de Change Data Capture.
- Não afirmar consumo apenas pela existência do evento.
