# Prompt — CustomObject

Use o prompt-base para criar um utilitário de documentação de `CustomObject`.

- Diretório: `objects/`; padrão: `*.object-meta.xml`.
- Tratar como componente composto.
- Analisar fields, validationRules, recordTypes, listViews, sharingReasons, webLinks e compactLayouts.
- Relacionar CustomField, PermissionSet, Profile, Flow, Apex e integrações.
- Comparar filhos criados, alterados e removidos.
