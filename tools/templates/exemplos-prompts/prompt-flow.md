# Prompt — Flow

Use o prompt-base para criar um utilitário de documentação de `Flow`.

- Diretório: `flows/`; padrão: `*.flow-meta.xml`.
- Identificar versão, status, tipo, elementos, decisões, loops, subflows, variáveis, fórmulas, ações, chamadas, referências e objetos.
- Avaliar HTTP Callout, Apex Actions, Subflows e Platform Events.
- Comparar versões e status ativo.
- Registrar fault paths e não inferir negócio apenas pelo nome de um elemento.
