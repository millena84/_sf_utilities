# Prompt — FlowCategory

Use o prompt-base para criar um utilitário de documentação de `FlowCategory`.

## Particularidades

- Identificar categoria, nome, descrição, status e flows associados.
- Relacionar Flow, FlowDefinition, processos, subflows e organização funcional.
- Diferenciar classificação do Flow de lógica executada.
- Avaliar impacto de reorganização, pesquisa e governança.
- Comparar alterações de nome, descrição, status e associações.
