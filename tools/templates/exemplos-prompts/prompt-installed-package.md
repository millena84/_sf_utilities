# Prompt — InstalledPackage

Use o prompt-base para criar um utilitário de documentação de `InstalledPackage`.

- Identificar namespace, versão, nome, dependências e status do pacote.
- Relacionar metadata pertencente ao pacote, componentes expostos, permissões e integrações.
- Diferenciar pacote instalado de código customizado local.
- Registrar diferenças entre ambientes e versões.
- Não inferir comportamento completo somente pelo namespace.
