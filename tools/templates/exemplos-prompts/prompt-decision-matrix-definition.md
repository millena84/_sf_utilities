# Prompt — DecisionMatrixDefinition

Use o prompt-base para criar um utilitário de documentação de `DecisionMatrixDefinition`.

## Particularidades

- Identificar matriz, dimensões, regras, resultados, versão e vigência.
- Relacionar DecisionTable, ExpressionSet, Flow e processos de decisão.
- Diferenciar matriz de decisão de resultado gerado em uma transação.
- Avaliar conflitos, cobertura, precedência e rastreabilidade.
- Comparar alterações de dimensões, regras, resultados e versão.
