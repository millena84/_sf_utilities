# Prompt — Orchestration

Use o prompt-base para criar um utilitário de documentação de `Orchestration`.

## Particularidades

- Identificar orquestração, etapas, gatilhos, ações, condições e status.
- Relacionar OrchestrationContext, Flow, Apex, ApprovalProcess, Task e integrações.
- Diferenciar definição de orquestração de execução instanciada.
- Avaliar paralelismo, dependências, retry, timeout, compensação e escalonamento.
- Comparar alterações de etapas, transições, ações e status.
