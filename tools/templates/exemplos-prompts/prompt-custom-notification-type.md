# Prompt — CustomNotificationType

Use o prompt-base para criar um utilitário de documentação de `CustomNotificationType`.

## Particularidades

- Identificar nome, canal, suporte a desktop e mobile e status.
- Relacionar Flow, Apex, usuários, grupos e aplicativos Lightning.
- Diferenciar tipo de notificação de evento que dispara a notificação.
- Avaliar risco de excesso de notificações ou divulgação indevida.
- Comparar alterações de canal, disponibilidade e aplicativos.
