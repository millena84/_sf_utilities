# Prompt — MessagingChannelUsage

Use o prompt-base para criar um utilitário de documentação de `MessagingChannelUsage`.

## Particularidades

- Identificar canal, objeto, uso, disponibilidade, permissões e contexto de atendimento.
- Relacionar MessagingChannel, Conversation, Case, ServiceChannel e usuários.
- Diferenciar configuração de uso de métricas ou conversas operacionais.
- Avaliar exposição de dados de clientes e acessos associados.
- Comparar alterações de objeto, canal, uso e permissões.
