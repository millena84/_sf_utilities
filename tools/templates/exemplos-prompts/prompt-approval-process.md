# Prompt — ApprovalProcess

Use o prompt-base para criar um utilitário de documentação de `ApprovalProcess`.

- Identificar objeto-alvo, critérios de entrada, etapas, aprovadores, ações de aprovação, rejeição, recall e submissão.
- Extrair ações automáticas, campos atualizados, tarefas, mensagens e dependências.
- Relacionar User, Queue, PermissionSet, Flow, Apex e objetos envolvidos.
- Distinguir configuração declarada no metadata do processo efetivamente executado na org.
- Documentar riscos de bloqueio, aprovação incompleta e automações concorrentes.
