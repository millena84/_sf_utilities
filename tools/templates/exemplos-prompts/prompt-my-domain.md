# Prompt — MyDomain

Use o prompt-base para criar um utilitário de documentação de `MyDomain`.

## Particularidades

- Identificar domínio, status, URL, redirecionamentos e configurações de login.
- Relacionar SsoSamlConfig, AuthProvider, Community, Site e certificados.
- Não expor domínios internos ou detalhes que facilitem ataques de autenticação.
- Diferenciar domínio registrado, implantado e ativo.
- Comparar alterações de domínio, status, redirecionamento e login.
