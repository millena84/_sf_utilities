# Prompt — FlowValueMap

Use o prompt-base para criar um utilitário de documentação de `FlowValueMap`.

## Particularidades

- Identificar mapa, entradas, chaves, valores, Flow associado e versão.
- Relacionar Flow, decisão, transformação, objetos e integrações.
- Diferenciar tabela de correspondência de dados operacionais reais.
- Avaliar valores ausentes, duplicados, padrões e comportamento de fallback.
- Comparar alterações de entradas, chaves, valores e versão.
