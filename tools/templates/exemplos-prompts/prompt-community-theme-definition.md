# Prompt — CommunityThemeDefinition

Use o prompt-base para criar um utilitário de documentação de `CommunityThemeDefinition`.

## Particularidades

- Identificar tema, tokens, cores, fontes, componentes, versão e status.
- Relacionar Community, ExperienceBundle, BrandingSet e páginas.
- Diferenciar tema de identidade visual aplicada em uma comunidade publicada.
- Não expor assets privados ou URLs internas desnecessárias.
- Comparar alterações de tokens, componentes, assets e versão.
