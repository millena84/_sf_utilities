# Prompt — ActionLinkGroupTemplate

Use o prompt-base para criar um utilitário de documentação de `ActionLinkGroupTemplate`.

## Particularidades

- Identificar grupo, links, rótulos, ações, contexto e permissões.
- Relacionar ActionLink, QuickAction, Flow, objetos e interfaces Lightning.
- Avaliar ações destrutivas, links externos e permissões exigidas.
- Diferenciar template de link de ação efetivamente acionada.
- Comparar alterações de links, ordem, rótulos e escopo de acesso.
