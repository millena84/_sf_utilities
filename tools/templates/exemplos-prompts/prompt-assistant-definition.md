# Prompt — AssistantDefinition

Use o prompt-base para criar um utilitário de documentação de `AssistantDefinition`.

## Particularidades

- Identificar assistente, finalidade, canais, contexto, status e versão.
- Relacionar AssistantVersion, AssistantSkill, PromptTemplate, Flow, Apex e objetos.
- Diferenciar definição do assistente de interação efetivamente executada.
- Avaliar escopo de dados, permissões, instruções e transferência para humano.
- Comparar alterações de versão, contexto, skills e canais.
