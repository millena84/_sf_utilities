# Prompt — AnalyticsSettings

Use o prompt-base para criar um utilitário de documentação de `AnalyticsSettings`.

## Particularidades

- Identificar habilitação, permissões, segurança, armazenamento e configurações globais.
- Relacionar AnalyticsWorkspace, WaveDataset, usuários, perfis e PermissionSet.
- Avaliar exposição de dados, compartilhamento e controles de governança.
- Diferenciar configuração global de ativo analítico específico.
- Comparar alterações de segurança, acesso, armazenamento e status.
