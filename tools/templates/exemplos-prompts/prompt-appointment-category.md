# Prompt — AppointmentCategory

Use o prompt-base para criar um utilitário de documentação de `AppointmentCategory`.

## Particularidades

- Identificar categoria, tipo de atendimento, duração, regras, território e status.
- Relacionar Appointment, WorkType, ServiceTerritory, canais e agendamento.
- Diferenciar categoria configurada de categoria disponível ao cliente.
- Avaliar conflitos, duração, elegibilidade, capacidade e governança.
- Comparar alterações de regras, duração, territórios, canais e status.
