# Prompt — Territory2

Use o prompt-base para criar um utilitário de documentação de `Territory2`.

- Identificar território, modelo, parent territory, estado e hierarquia.
- Relacionar usuários, contas, regras de atribuição, grupos e acesso a registros.
- Diferenciar território de role e de grupo.
- Documentar impacto sobre acesso e distribuição de contas.
- Comparar alterações hierárquicas e de ativação.
