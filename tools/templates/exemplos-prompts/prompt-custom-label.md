# Prompt — CustomLabel

Use o prompt-base para criar um utilitário de documentação de `CustomLabel`.

- Identificar nome, valor, idioma, categoria, proteção e descrição.
- Tratar o valor como potencialmente sensível conforme o domínio.
- Relacionar Apex, LWC, Flow, Visualforce, Aura e traduções.
- Não expor segredos armazenados indevidamente em labels.
