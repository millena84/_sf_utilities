# Prompt — WaveLens

Use o prompt-base para criar um utilitário de documentação de `WaveLens`.

## Particularidades

- Identificar lens, dataset, dimensões, medidas, filtros, ordenação e proprietário.
- Relacionar WaveDataset, WaveDashboard, AnalyticsVisualization e consultas.
- Diferenciar exploração analítica de dashboard publicado.
- Não expor resultados com PII ou dados restritos.
- Comparar alterações de filtros, medidas, dimensões, ordenação e dataset.
