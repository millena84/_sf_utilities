# Prompt — DecisionTable

Use o prompt-base para criar um utilitário de documentação de `DecisionTable`.

## Particularidades

- Identificar tabela, entradas, condições, resultados, prioridade e status.
- Relacionar Flow, ExpressionSet, Apex, objetos e processos de negócio.
- Diferenciar tabela publicada de decisão efetivamente avaliada.
- Avaliar sobreposição de regras, ausência de correspondência e ordem de prioridade.
- Comparar alterações de condições, resultados, prioridade e versão.
