# Prompt — ApexTestSuite

Use o prompt-base para criar um utilitário de documentação de `ApexTestSuite`.

- Identificar nome da suite e classes de teste incluídas.
- Relacionar ApexClass, métodos de teste, execução e cobertura.
- Diferenciar classes declaradas daquelas efetivamente executadas.
- Registrar ambiente, versão de API, data e resultado quando disponíveis.
- Não afirmar cobertura sem evidência de execução.
