# Prompt — Appointment

Use o prompt-base para criar um utilitário de documentação de `Appointment`.

## Particularidades

- Identificar agendamento, cliente, serviço, recurso, horário, território e status.
- Relacionar ServiceAppointment, WorkType, ServiceResource, AppointmentTopic e Field Service.
- Não expor PII, endereço, telefone, localização ou detalhes sensíveis do cliente.
- Diferenciar agendamento criado de agendamento confirmado, atendido ou cancelado.
- Comparar alterações de horário, recurso, status, território e duração.
