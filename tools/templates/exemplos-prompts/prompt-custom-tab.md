# Prompt — CustomTab

Use o prompt-base para criar um utilitário de documentação de `CustomTab`.

- Identificar tipo, objeto ou recurso associado, label, visibilidade e configuração.
- Relacionar CustomObject, WebTab, Lightning Page, CustomApplication, Profile e PermissionSet.
- Diferenciar tab de objeto e tab web.
- Não inferir acesso efetivo apenas pela existência da tab.
