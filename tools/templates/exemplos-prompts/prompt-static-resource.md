# Prompt — StaticResource

Use o prompt-base para criar um utilitário de documentação de `StaticResource`.

- Identificar nome, extensão, cache control, tamanho e conteúdo permitido.
- Diferenciar arquivo simples de ZIP ou pacote.
- Relacionar LWC, Aura, Visualforce, Apex e páginas consumidoras.
- Não extrair secrets ou dados sensíveis.
- Registrar hash para comparação.

Fonte: [StaticResource Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_staticresource.htm)
