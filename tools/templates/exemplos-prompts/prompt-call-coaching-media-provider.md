# Prompt — CallCoachingMediaProvider

Use o prompt-base para criar um utilitário de documentação de `CallCoachingMediaProvider`.

## Particularidades

- Identificar provedor, mídia, retenção, integrações, permissões e status.
- Relacionar VoiceCall, CallCenter, gravações, transcrições e políticas de privacidade.
- Não expor conteúdo de chamadas, URLs de mídia ou credenciais de provedor.
- Diferenciar configuração de mídia de gravação ou análise efetivamente produzida.
- Avaliar consentimento, retenção, acesso e riscos regulatórios.
