# Prompt — OrchestrationContext

Use o prompt-base para criar um utilitário de documentação de `OrchestrationContext`.

## Particularidades

- Identificar contexto, entradas, variáveis, objeto de negócio e orquestração associada.
- Relacionar Orchestration, Flow, Case, Opportunity, User e registros.
- Diferenciar contexto configurado de instância ou execução real.
- Avaliar exposição de dados, escopo, persistência e consistência.
- Comparar alterações de entradas, variáveis, objeto e relacionamento.
