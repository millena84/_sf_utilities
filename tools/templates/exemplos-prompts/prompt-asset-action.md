# Prompt — AssetAction

Use o prompt-base para criar um utilitário de documentação de `AssetAction`.

## Particularidades

- Identificar ação, asset, tipo, parâmetros, permissões, status e origem.
- Relacionar Asset, AssetActionSource, automações, Flow, Apex e integrações.
- Não expor tokens, payloads sensíveis ou dados pessoais.
- Diferenciar ação configurada de ação efetivamente executada.
- Comparar alterações de parâmetros, permissões, origem, status e versão.
