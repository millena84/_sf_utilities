# Prompt — EmbeddedServiceMenuSettings

Use o prompt-base para criar um utilitário de documentação de `EmbeddedServiceMenuSettings`.

## Particularidades

- Identificar itens, ordem, canais, links, ações e disponibilidade do menu.
- Relacionar EmbeddedServiceConfig, QuickAction, Flow, Knowledge e canais.
- Não expor links privados ou ações administrativas indevidas.
- Diferenciar menu configurado de recurso efetivamente selecionado.
- Comparar alterações de ordem, itens, links e disponibilidade.
