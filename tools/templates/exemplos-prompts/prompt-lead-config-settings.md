# Prompt — LeadConfigSettings

Use o prompt-base para criar um utilitário de documentação de `LeadConfigSettings`.

## Particularidades

- Identificar configurações de conversão, atribuição, status e captura de leads.
- Relacionar Lead, LeadStatus, AssignmentRules, WebToLead e DuplicateRules.
- Diferenciar configuração de conversão de uma conversão efetivamente realizada.
- Avaliar impacto em qualidade, roteamento e deduplicação.
- Comparar alterações de status, campos e comportamento de conversão.
