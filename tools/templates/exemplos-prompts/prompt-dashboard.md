# Prompt — Dashboard

Use o prompt-base para criar um utilitário de documentação de `Dashboard`.

- Identificar pasta, componentes, relatórios de origem, filtros, layout e usuário de execução.
- Relacionar Report, ReportType, objetos, campos, pasta e permissões.
- Diferenciar configuração dos dados exibidos no momento.
- Tratar dados exibidos como potencialmente sensíveis.
- Comparar mudanças de layout, fontes e filtros.
