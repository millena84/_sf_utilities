# Prompt — NotificationTypeConfig

Use o prompt-base para criar um utilitário de documentação de `NotificationTypeConfig`.

## Particularidades

- Identificar tipo, canais, preferências e contexto de entrega.
- Relacionar CustomNotificationType, usuários, dispositivos e aplicativos.
- Não expor identificadores de dispositivos ou dados pessoais desnecessários.
- Diferenciar configuração de entrega de envio efetivo.
- Comparar alterações de canal, preferência e disponibilidade.
