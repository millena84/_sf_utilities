# Prompt — OrgWideEmailAddress

Use o prompt-base para criar um utilitário de documentação de `OrgWideEmailAddress`.

## Particularidades

- Identificar display name, endereço mascarado, perfil de acesso e verificação.
- Relacionar EmailTemplate, Flow, Apex, Case e processos de comunicação.
- Não expor endereços completos quando não for necessário.
- Diferenciar endereço configurado de endereço verificado e autorizado.
- Comparar alterações de nome, verificação, perfil e disponibilidade.
