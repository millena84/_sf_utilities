# Prompt — ApexPage / VisualforcePage

Use o prompt-base para criar um utilitário de documentação de páginas Visualforce.

- Identificar arquivo, metadata, controller, extensions e componentes usados.
- Relacionar ApexClass, ApexPage, VisualforceComponent, objetos, campos, permissões e integrações.
- Considerar conteúdo, API version, disponibilidade e exposição.
- Não analisar HTML isoladamente sem controller e dependências.

Fonte: [ApexPage Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_pages.htm)
