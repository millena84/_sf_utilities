# Prompt — Community

Use o prompt-base para criar um utilitário de documentação de `Community`.

## Particularidades

- Identificar nome, URL, tema, status, perfil e configurações de acesso.
- Relacionar Network, ExperienceBundle, usuários externos, objetos e páginas.
- Não expor domínios privados, credenciais ou dados de usuários.
- Avaliar superfícies públicas e controles de acesso.
- Comparar alterações de status, URL, tema e publicação.
