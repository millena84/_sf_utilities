# Prompt — CallCenter

Use o prompt-base para criar um utilitário de documentação de `CallCenter`.

## Particularidades

- Identificar adaptador CTI, nome, versão, usuários, permissões e configuração do provedor.
- Relacionar CallCenterRoutingMap, User, PermissionSet, Softphone e integrações de telefonia.
- Não expor endpoints privados, tokens, chaves ou dados de chamadas.
- Diferenciar configuração de call center de sessão ou chamada efetivamente realizada.
- Comparar alterações de adaptador, usuários, permissões e disponibilidade.
