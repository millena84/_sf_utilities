# Prompt — PermissionSetLicense

Use o prompt-base para criar um utilitário de documentação de `PermissionSetLicense`.

- Identificar licença, status, namespace, permissões incluídas e dependências.
- Relacionar PermissionSet, PermissionSetGroup, User e atribuições de licença.
- Diferenciar licença disponível de licença atribuída.
- Comparar alterações de disponibilidade e atribuição quando a fonte permitir.
- Não expor dados pessoais desnecessários.
