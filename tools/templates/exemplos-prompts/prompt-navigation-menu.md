# Prompt — NavigationMenu

Use o prompt-base para criar um utilitário de documentação de `NavigationMenu`.

## Particularidades

- Identificar menu, itens, ordem, links, páginas, audiências e status.
- Relacionar Community, Experience Cloud, DigitalExperienceBundle e conteúdo.
- Avaliar links externos, acesso público, autorização e navegação quebrada.
- Diferenciar menu configurado de navegação efetivamente apresentada.
- Comparar alterações de itens, ordem, links, audiência e status.
