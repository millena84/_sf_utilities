# Prompt — ReportType

Use o prompt-base para criar um utilitário de documentação de `ReportType`.

- Identificar objeto primário, objetos relacionados, relacionamentos e campos disponíveis.
- Documentar escopo, status, categorias, colunas e filtros padrão.
- Relacionar Reports, objetos, campos e permissões.
- Avaliar impacto das alterações nos relacionamentos.
- Identificar relatórios dependentes.
