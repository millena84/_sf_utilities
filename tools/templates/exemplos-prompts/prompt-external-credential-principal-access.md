# Prompt — External Credential Principal e acesso

Use o prompt-base para criar um utilitário de documentação do acesso a principals de `ExternalCredential`.

- Identificar principal, PermissionSet, PermissionSetGroup, NamedCredential e ExternalCredential.
- Documentar quem pode usar a credencial sem revelar seu valor.
- Diferenciar configuração da credencial de autorização para uso.
- Avaliar risco de privilégio excessivo.
- Comparar mudanças de principal e atribuição.
