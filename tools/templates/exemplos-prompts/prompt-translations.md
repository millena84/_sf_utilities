# Prompt — Translations

Use o prompt-base para criar um utilitário de documentação de `Translations`.

- Identificar idioma e componentes traduzidos.
- Documentar traduções de labels, campos, objetos, tabs, record types, picklists e mensagens suportadas.
- Relacionar CustomObjectTranslation, CustomLabel, CustomField, CustomTab e idioma da org.
- Comparar alterações por idioma e componente.
- Não sobrescrever tradução com inferência automática.
