# Prompt — ActionPlanTemplate

Use o prompt-base para criar um utilitário de documentação de `ActionPlanTemplate`.

## Particularidades

- Identificar plano, etapas, tarefas, responsáveis, prazos, objetos e status.
- Relacionar Task, Flow, Case, Account, Opportunity e processos de atendimento.
- Diferenciar template de plano de ação executado para um registro.
- Avaliar prazos, dependências, responsáveis e tarefas duplicadas.
- Comparar alterações de etapas, prazos, responsáveis e critérios.
