# Exemplos de prompts para criação de utilitários Salesforce

Esta pasta contém um prompt-base e exemplos especializados para criar utilitários de documentação de metadata Salesforce.

## Fontes consideradas

Os prompts orientam a análise de XML Salesforce, tabela interna padronizada, API padrão ou Metadata API, Tooling API quando aplicável, `sf data query`, código, configuração e documentação do projeto.

## Uso

1. Leia `prompt-base-criacao-utilitario.md`.
2. Escolha o prompt específico do metadata.
3. Substitua os placeholders.
4. Informe projeto, org, versão da API e modo de execução.
5. Valide as fontes oficiais e os contratos atuais antes da implementação.
