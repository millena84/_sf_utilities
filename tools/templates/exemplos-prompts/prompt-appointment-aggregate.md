# Prompt — AppointmentAggregate

Use o prompt-base para criar um utilitário de documentação de `AppointmentAggregate`.

## Particularidades

- Identificar agregado, métricas, período, território, recurso, filtros e status.
- Relacionar Field Service, Appointment, ServiceAppointment e capacidade operacional.
- Não expor dados pessoais de clientes, localização sensível ou agenda individual.
- Diferenciar agregado calculado de agendamentos efetivamente confirmados.
- Comparar alterações de métricas, dimensões, filtros, período e atualização.
