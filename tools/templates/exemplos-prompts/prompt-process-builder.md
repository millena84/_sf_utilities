# Prompt — ProcessBuilder

Use o prompt-base para criar um utilitário de documentação de processos legados do Process Builder.

- Identificar objeto, critérios, ações imediatas, ações agendadas e dependências.
- Relacionar WorkflowRule, Flow, Apex, FieldUpdate, EmailAlert e OutboundMessage.
- Registrar que se trata de automação legada quando aplicável.
- Identificar possível migração ou coexistência com Flow.
- Não afirmar equivalência entre Process Builder e Flow sem análise funcional.
