# Prompt — Queue

Use o prompt-base para criar um utilitário de documentação de `Queue`.

- Identificar nome, label, membros, objetos suportados e regras de acesso.
- Relacionar QueueSobject, Group, User, Role, Case, Lead e objetos customizados.
- Documentar quem pode visualizar, assumir ou operar registros da fila.
- Comparar membros, objetos suportados e alterações de acesso.

Fonte: [Queue — Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_queue.htm)
