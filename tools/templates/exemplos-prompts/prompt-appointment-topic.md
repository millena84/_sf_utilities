# Prompt — AppointmentTopic

Use o prompt-base para criar um utilitário de documentação de `AppointmentTopic`.

## Particularidades

- Identificar tópico, serviço, duração, elegibilidade, canais, território e status.
- Relacionar AppointmentCategory, WorkType, Appointment, recursos e clientes.
- Diferenciar tópico de agendamento de appointment efetivamente criado.
- Avaliar regras de disponibilidade, capacidade, conflito e experiência do cliente.
- Comparar alterações de duração, regras, canais, territórios e status.
