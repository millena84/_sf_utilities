# Prompt — AnalyticSnapshot

Use o prompt-base para criar um utilitário de documentação de `AnalyticSnapshot`.

- Identificar relatório de origem, objeto-alvo, mapeamento de campos, frequência e usuário executor.
- Documentar a transformação de resultados em registros históricos.
- Relacionar Report, CustomObject, CustomField, agendamento e permissões.
- Diferenciar definição do snapshot dos dados históricos gravados.
- Registrar periodicidade e campos sensíveis.

Fonte: [AnalyticSnapshot Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_analyticsnapshot.htm)
