# Prompt — Letterhead

Use o prompt-base para criar um utilitário de documentação de `Letterhead`.

## Particularidades

- Identificar nome, pasta, marca, cabeçalho, rodapé, cores e imagens configuradas.
- Relacionar EmailTemplate e identidade visual da organização.
- Não expor URLs privadas, identificadores internos ou ativos sensíveis.
- Diferenciar recurso de apresentação de regra de envio.
- Comparar alterações visuais e impacto nos templates dependentes.
