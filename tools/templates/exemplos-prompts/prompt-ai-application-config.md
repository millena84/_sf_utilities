# Prompt — AIApplicationConfig

Use o prompt-base para criar um utilitário de documentação de `AIApplicationConfig`.

## Particularidades

- Identificar aplicação, modelo, parâmetros, limites, status e políticas.
- Relacionar AIApplication, ExternalAIModel, PromptTemplate e permissões.
- Não expor chaves, endpoints privados, prompts confidenciais ou tokens.
- Diferenciar configuração de execução efetiva ou resposta gerada.
- Avaliar custos, limites, segurança, retenção e controles de saída.
