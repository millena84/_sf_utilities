# Prompt — BusinessProcess

Use o prompt-base para criar um utilitário de documentação de `BusinessProcess`.

- Identificar objeto, processo, valores de status e record types associados.
- Relacionar RecordType, Case, Lead, Solution, Status e automações.
- Diferenciar valores possíveis de status e valores efetivamente usados.
- Comparar alterações de status, disponibilidade e associação.
- Documentar impactos em Flow, ValidationRule, Apex e integrações.
