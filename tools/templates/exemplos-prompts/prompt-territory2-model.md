# Prompt — Territory2Model

Use o prompt-base para criar um utilitário de documentação de `Territory2Model`.

- Identificar modelo, estado, versão, territórios e regras associadas.
- Documentar ciclo de planejamento, ativação, arquivamento e distribuição.
- Relacionar Territory2, Territory2Type, Territory2Rule e usuários.
- Diferenciar modelo planejado de modelo ativo.
- Comparar mudanças entre versões e ambientes.
