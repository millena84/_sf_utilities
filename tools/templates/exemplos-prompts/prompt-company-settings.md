# Prompt — CompanySettings

Use o prompt-base para criar um utilitário de documentação de `CompanySettings`.

## Particularidades

- Identificar informações da organização, moeda, idioma, país, fuso e preferências corporativas.
- Relacionar Organization, User, CurrencyType, BusinessHours e configurações regionais.
- Não expor identificadores internos ou dados corporativos desnecessários.
- Diferenciar dado institucional de configuração funcional.
- Comparar alterações de localidade, moeda, fuso e preferências.
