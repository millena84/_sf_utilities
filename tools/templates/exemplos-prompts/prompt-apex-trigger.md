# Prompt — ApexTrigger

Use o prompt-base para criar um utilitário de documentação de `ApexTrigger`.

- Identificar objeto e eventos before/after insert/update/delete/undelete.
- Localizar classe ou lógica chamada.
- Relacionar Flow, automações, validações e integrações.
- Avaliar recursão, bulkificação, ordem e side effects.
- Não assumir ordem de execução sem evidência.
