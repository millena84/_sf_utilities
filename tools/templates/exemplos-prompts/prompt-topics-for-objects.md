# Prompt — TopicsForObjects

Use o prompt-base para criar um utilitário de documentação de `TopicsForObjects`.

## Particularidades

- Identificar objetos habilitados, campos e regras de uso de tópicos.
- Relacionar Topic, KnowledgeArticle, feeds e pesquisa.
- Diferenciar habilitação no objeto de tópico efetivamente atribuído.
- Avaliar impacto em classificação, navegação e descoberta.
- Comparar alterações de objetos, campos e disponibilidade.
