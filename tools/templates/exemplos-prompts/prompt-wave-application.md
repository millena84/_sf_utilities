# Prompt — WaveApplication

Use o prompt-base para criar um utilitário de documentação de `WaveApplication`.

## Particularidades

- Identificar aplicação, workspace, dashboards, datasets, proprietário e status.
- Relacionar WaveDashboard, WaveDataset, WaveLens, WaveRecipe e usuários.
- Diferenciar aplicação analítica de dashboard ou dataset individual.
- Avaliar compartilhamento, dependências, atualização e publicação.
- Comparar alterações de ativos, proprietário, acesso e status.
