# Prompt — DigitalExperienceConfig

Use o prompt-base para criar um utilitário de documentação de `DigitalExperienceConfig`.

## Particularidades

- Identificar site, domínio, publicação, autenticação, configurações e status.
- Relacionar DigitalExperienceBundle, Community, Network, MyDomain e usuários externos.
- Não expor domínios privados, credenciais ou configurações de acesso sensíveis.
- Diferenciar configuração do site de publicação efetivamente ativa.
- Comparar alterações de domínio, autenticação, publicação e status.
