# Prompt — Profile

Use o prompt-base para criar um utilitário de documentação de `Profile`.

- Analisar permissões de objeto, campo, sistema, usuário, Apex, Visualforce, apps, tabs, layouts e Connected Apps.
- Relacionar PermissionSet, PermissionSetGroup, User, licença e perfil base.
- Destacar privilégios de alto impacto.
- Separar permissões declaradas de usuários efetivamente atribuídos.
- Não expor dados pessoais desnecessários.
