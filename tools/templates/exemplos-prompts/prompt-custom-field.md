# Prompt — CustomField

Use o prompt-base para criar um utilitário de documentação de `CustomField`.

- Identificar objeto pai e campo.
- Extrair tipo, label, comprimento, precisão, escala, obrigatoriedade, default, fórmula e relacionamento.
- Distinguir campo técnico, label e fórmula.
- Relacionar Field Level Security, PermissionSet, Profile, Flow, Apex e integrações.
- Não confundir definição de metadata com valores de dados.
- Alertar mudanças potencialmente destrutivas.
