# Prompt — Group

Use o prompt-base para criar um utilitário de documentação de `Group`.

- Identificar grupo, tipo, membros, filas, roles e grupos aninhados.
- Relacionar SharingRules, SharingSet, queues, territórios e acesso a registros.
- Não expor dados pessoais desnecessários.
- Diferenciar grupo público, grupo de fila e grupo relacionado à hierarquia.
- Comparar alterações de membros e composição.
