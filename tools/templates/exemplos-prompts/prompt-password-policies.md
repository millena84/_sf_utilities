# Prompt — PasswordPolicies

Use o prompt-base para criar um utilitário de documentação de `PasswordPolicies`.

- Identificar complexidade, expiração, histórico, bloqueio e recuperação de senha.
- Tratar configurações como informação sensível de segurança.
- Relacionar SecuritySettings, SessionSettings, Profile, Identity e SSO.
- Não expor valores que aumentem risco operacional.
- Comparar mudanças de política e impacto de conformidade.
