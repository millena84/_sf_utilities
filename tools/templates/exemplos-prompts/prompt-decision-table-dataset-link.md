Use o prompt-base para criar um utilitário de documentação de `DecisionTableDatasetLink`.

- Identificar tabela, dataset, origem, campos, chave e relacionamento.
- Relacionar DecisionTable, DataSource, objetos, campos e integrações.
- Avaliar qualidade, atualidade, permissões e exposição dos dados de entrada.
- Diferenciar vínculo configurado de dataset efetivamente consultado.
- Comparar alterações de origem, campos, chave e status.
