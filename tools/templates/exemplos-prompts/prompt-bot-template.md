# Prompt — BotTemplate

Use o prompt-base para criar um utilitário de documentação de `BotTemplate`.

## Particularidades

- Identificar template, produto, idioma, intenção, blocos padrão e versão.
- Relacionar Bot, BotVersion, BotBlock, Flow e canais.
- Diferenciar modelo reutilizável de bot implantado.
- Avaliar dependências, customizações e informações fornecidas ao usuário.
- Comparar alterações de blocos, idioma, versão e configuração inicial.
