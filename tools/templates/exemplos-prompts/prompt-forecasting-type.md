# Prompt — ForecastingType

Use o prompt-base para criar um utilitário de documentação de `ForecastingType`.

## Particularidades

- Identificar tipo de forecast, objeto, categoria, métricas, períodos e status.
- Relacionar ForecastingSourceDefinition, ForecastingFilter, ForecastingItem e hierarquia.
- Diferenciar tipo de previsão de valor previsto para um período.
- Avaliar consistência entre categorias, métricas, moeda e periodicidade.
- Comparar alterações de objeto, métricas, período, status e hierarquia.
