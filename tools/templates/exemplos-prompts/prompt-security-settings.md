# Prompt — SecuritySettings

Use o prompt-base para criar um utilitário de documentação de `SecuritySettings`.

- Identificar configurações de rede, senha, sessão, login e SSO disponíveis.
- Tratar o componente como composto, preservando subestruturas.
- Relacionar NetworkAccess, PasswordPolicies, SessionSettings, LoginFlows e autenticação.
- Não expor segredos, certificados ou dados sensíveis.
- Comparar alterações por categoria e impacto.

Fonte: [SecuritySettings — Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/meta_securitysettings.htm)
