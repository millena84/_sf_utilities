# Prompt — CompactLayout

Use o prompt-base para criar um utilitário de documentação de `CompactLayout`.

- Identificar objeto pai, label, campos e layout primário.
- Relacionar Lightning Record Page, páginas, aplicativos e experiência de usuário.
- Diferenciar layout declarado de layout efetivamente atribuído.
- Verificar campos sensíveis e dados exibidos.
