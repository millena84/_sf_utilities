# Prompt — AssetTokenEvent

Use o prompt-base para criar um utilitário de documentação de `AssetTokenEvent`.

## Particularidades

- Identificar evento, asset, token, origem, timestamp, tipo e status.
- Relacionar Asset, AssetToken, eventos operacionais, IoT e integrações.
- Não expor tokens reais, identificadores sensíveis ou payloads completos.
- Diferenciar evento registrado de processamento, alerta ou ação concluída.
- Comparar alterações de esquema, origem, tipos, correlação e retenção.
