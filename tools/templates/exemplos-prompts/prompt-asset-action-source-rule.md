# Prompt — AssetActionSourceRule

Use o prompt-base para criar um utilitário de documentação de `AssetActionSourceRule`.

## Particularidades

- Identificar regra, fonte, prioridade, critérios, ação, vigência e status.
- Relacionar AssetActionSource, AssetAction, regras de decisão e automação.
- Não expor critérios confidenciais ou dados de clientes.
- Diferenciar regra configurada de regra efetivamente aplicada.
- Comparar alterações de critérios, prioridade, vigência, ação e status.
