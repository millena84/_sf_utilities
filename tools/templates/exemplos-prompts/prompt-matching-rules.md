# Prompt — MatchingRules

Use o prompt-base para criar um utilitário de documentação de `MatchingRules`.

- Identificar objeto, campos comparados e método de matching.
- Documentar normalização, fórmulas, comparadores, filtros e lógica de correspondência.
- Relacionar DuplicateRules e objetos associados.
- Avaliar falsos positivos, falsos negativos e impacto em integrações.
