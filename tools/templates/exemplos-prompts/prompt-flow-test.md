# Prompt — FlowTest

Use o prompt-base para criar um utilitário de documentação de `FlowTest`.

## Particularidades

- Identificar Flow, cenário, entradas, dados de teste, expectativas e status.
- Relacionar FlowVersion, objetos, elementos, testes automatizados e deployments.
- Não expor dados reais ou PII usados em cenários de teste.
- Diferenciar teste definido de teste executado e aprovado.
- Comparar alterações de entradas, expectativas, cobertura e versão.
