# Prompt — DiscoveryStory

Use o prompt-base para criar um utilitário de documentação de `DiscoveryStory`.

## Particularidades

- Identificar story, objetivo, insights, dados, modelo, audiência e status.
- Relacionar DiscoveryGoal, DiscoveryAIModel, datasets, dashboards e recomendações.
- Diferenciar narrativa analítica de insight ou ação efetivamente apresentada.
- Não expor PII, dados confidenciais ou conclusões sem evidência.
- Comparar alterações de dados, modelo, insights, audiência e status.
