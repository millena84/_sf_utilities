# Prompt — VoiceCallSettings

Use o prompt-base para criar um utilitário de documentação de `VoiceCallSettings`.

## Particularidades

- Identificar habilitação, provedores, gravação, transcrição, filas, status e preferências de voz.
- Relacionar VoiceCall, CallCenter, ServiceChannel, Queue, User e CallCoachingMediaProvider.
- Não expor gravações, transcrições, telefones, URLs privadas ou segredos.
- Diferenciar configuração de voz de ligação efetivamente realizada.
- Avaliar retenção, consentimento, roteamento e riscos regulatórios.
