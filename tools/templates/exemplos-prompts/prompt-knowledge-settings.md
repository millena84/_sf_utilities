# Prompt — KnowledgeSettings

Use o prompt-base para criar um utilitário de documentação de `KnowledgeSettings`.

## Particularidades

- Identificar habilitação, canais, tipos de artigo, busca e configurações de publicação.
- Relacionar KnowledgeArticle, DataCategoryGroup, Experience Cloud e permissões.
- Diferenciar configuração global de artigo ou categoria específica.
- Avaliar impacto em publicação, pesquisa e acesso ao conhecimento.
- Comparar alterações de canais, status e opções de busca.
