# Prompt — AutoResponseRules

Use o prompt-base para criar um utilitário de documentação de `AutoResponseRules`.

- Identificar objeto, regra ativa, critérios e ordem de avaliação.
- Documentar template, remetente, destinatário, idioma e condições de disparo.
- Relacionar EmailTemplate, Organization-Wide Email Address, Case, Lead e automações.
- Não expor endereços ou dados sensíveis desnecessários.
